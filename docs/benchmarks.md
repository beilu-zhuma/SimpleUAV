# UAV-ON评测协议

官方UAV-ON 1.0 valset共1000条，排除CityPark、BrushifyRoad、Slum、DownTown后使用固定733条健康任务，记录全部排除身份和分母，不补抽。安装、配置和运行步骤见[中文使用说明](../README.zh-CN.md)。

采用四视图原生RGB-D、物理速度控制，出生上调2m，最多150次高层决策。历史4轮保留所选视图、动作与真实执行反馈，文字摘要最多1200字符。每轮两个VLM阶段：当前帧目标核查与带上下文导航，目标动作绑定本轮候选。开局90°扫描可开关、默认关闭，开启后计入一次总决策预算。单段6m，STOP估距10m，主评分距离20m；不能把STOP估距门限混同离线成功阈值。

深度定位使用25%分位前景采样；控制器包含上升保护、受阻方向过滤、下降接近的水平回退和纯上升覆盖豁免。深度安全检查不保证完全避免碰撞。MTP关闭、Prefix Cache开启。

碰撞从专用simGetCollisionInfo读取并锁存。出生碰撞属于正常失败终态，额外记录spawn_collision；不作为整批启动异常。碰撞立即失败，SR/OSR/SPL均为0。

SR要求接受STOP且终点在20m内。OSR使用决策终点及原实现的终止边界，出生点和控制中间样本不混入主OSR；密集最近距离仅诊断。SPL使用数据集原geodesic distance及完整实际采样路径，零路径贡献0。NE记录最终目标距离，保留官方20m与原评分数学核验。

`metrics-only`保存SR/OSR/SPL/NE及评分所需标量，不留RGB-D和详细位姿；`full`保存详细记录。基础设施缺测单列，缺失/重复身份不得发布完整733条成绩。恢复保留attempt与已结算身份，使用原冻结入口，不重跑已结算任务或刷新累计恢复预算。

本实现标为UAV-ON 1.0 adjusted protocol；任务过滤、出生高度、物理控制、决策预算与官方历史离散动作实现的差异应与成绩一同披露。
